# Site institucional

Esta pasta agora usa `React + Vite + Tailwind`.

## Desenvolvimento local

- `npm install`
- `npm run dev`

## Build

- `npm run build`

O output fica em `site/dist`.

## Deploy no Render

- Root directory: `site`
- Build command: `npm install && npm run build`
- Publish directory: `dist`

## Objetivo

O site institucional deve:

- apresentar a marca
- receber campanhas e banners
- levar o visitante para `app.lindice.com.br`

O que nao deve entrar aqui:

- login funcional interno
- checkout
- carrinho
- painel
- rotas da TWA
